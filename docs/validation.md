| Проверка | Результат |
|---|---|
| `python -m pytest -q`, Windows | 34 passed |
| `docker build -t nti-lab:latest .` | Успешная сборка |
| `docker run --rm nti-lab:latest python -m pytest -q`, Linux | 33 passed, 1 skipped |
| Синтаксис браузерного JavaScript (`node --check`) | Без ошибок |
| HTTP Range браузерного MP4 | 206 Partial Content; запрошенные 1024 байта получены |
| API сигнала в пределах записи | 5000 точек ЭКГ в 20-секундном окне, спектр RR |
| API сигнала вне записи | `outside_recording`, спектр отсутствует |
| Браузер | Выбор сессии, покадровый шаг, переход к контексту истории, воспроизведение, пауза и наложение ROI проверены |
| Консоль браузера | Ошибок при проверенных действиях нет |

Linux-тест пропущен ожидаемо: он проверяет реальный локальный BCRX и запускается только при наличии личных исходников. Они не входят в Docker image и Git. Численные тесты используют искусственные сигналы с известной частотой, пропусками, артефактами и временным сдвигом. Это проверка реализации, не измерение точности на людях.

Чтобы повторить проверку актуального кода внутри уже собранного образа, допускается подключить `src/` и `tests/` как read-only bind mounts; итоговая сборка включает те же файлы. Публичный CI повторяет численные тесты и сборку.

`scripts/audit_audio.py` проверяет наличие и целостность результатов речи. `scripts/audit_project.py` проверяет длительности, временные шкалы, наличие результатов всех модальностей и сохраняет `outputs/audit/project.json` и таблицу доступности видеоаналитики. Их численные результаты зависят от локального набора данных и не публикуются в коде.

Скриншот интерфейса на личных записях хранится только локально: `outputs/report/interface.png`. Полный PDF и изображения его страниц также остаются локальными.

## Что этими проверками не установлено

Автоматические R-пики, ASR, диаризация, качество rPPG и кандидаты синхронизации не сверены с независимой экспертной разметкой всего набора. Повторное распознавание спорного фрагмента другой моделью уменьшает зависимость от одного декодирования, но не заменяет прослушивание экспертом.

Закрытые глаза помогают найти спокойный участок видео, но сами по себе не дают метки в часах прибора. Корреляционные смещения остаются неподтверждёнными и сопровождаются неопределённостью. Перекрывающиеся окна не считаются независимыми наблюдениями.
