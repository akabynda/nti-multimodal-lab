# Совместный анализ профилей и измерений

## Вход и запуск

`scripts/analyze_multimodal.py` объединяет анкетные профили с признаками речи, видео и BioRadio.

```powershell
python scripts/analyze_multimodal.py --label-review path/to/label_review.json --assumption-helper path/to/assumption_checks.py --output-dir outputs/research/multimodal
```

`--label-review` — JSON разметки целых ответов: границы в шкале видео, цитаты и SHA-256 стенограмм и эталонов. `--assumption-helper` — файл `assumption_checks.py` навыка Statistical Analysis. Для изменённой разметки задайте новый `--output-dir`: сохранённый план расчёта проверяется на совпадение.

Классы: `0` — соответствие эталону; `1` — отрицание факта, замена события, примера или существенной детали. При нескольких утверждениях метка `1` назначается при хотя бы одном несоответствии. Дополнение вне проверяемого факта и отсутствие ответа не получают метку `1`. Повторные ссылки на один ответ объединяются. Темы записываются в `topic_audit.json`.

## Признаки

- Акустические окна целиком помещаются в речь респондента. Межсловные паузы рассчитываются по актуальным временным меткам слов.
- ЭКГ и RIP берутся из 120-секундного окна контекста ответа. Некачественное ближайшее окно даёт пропуск.
- Агрегаты ЭКГ, RIP и rPPG по участнику требуют не менее 20% пригодных окон.
- Пропуски сохраняются как NaN с причиной в результатах извлечения.
- Естественный и демонстрируемый типы кодируются признаками наличия компонентов. Эмоциональный баланс не включается одновременно с положительным и отрицательным показателями.

## Методы

| Расчёт | Параметры |
|---|---|
| Корреляции | Спирмен; точные двусторонние перестановки одного вектора; минимум 6 участников |
| Основная семья | Выраженность и эмоциональный баланс × F0, темп речи, скорость головы, движение торса, ЧСС ЭКГ, RMSSD |
| Дополнительная семья | Остальные пары числовых профилей и признаков |
| Поправка и интервалы | Холм отдельно по семьям; парный bootstrap по участникам; нерасчётные проверки остаются в размере семьи |
| Классификация | L2-логистическая регрессия, `C=0.1`, порог `0.5`, без подбора параметров |
| Разделение | Leave-one-participant-out; взвешенная медианная импутация и масштабирование на обучающей части |
| Веса | Суммарный вес каждого участника равен 1 |
| Основная метрика | Средний Brier по участникам; сравнение видео и речи с добавлением анкеты |
| BioRadio | Отдельное сравнение при исходном смещении и на границах сохранённого интервала |
| Интервалы модели | 95% bootstrap по участникам при фиксированных прогнозах LOPO |

Предикторы — измерения и анкета. Идентификаторы, темы, вопросы, эталоны и результаты текстового сопоставления исключены.

## Метки «Правда», «Ложь», «База» и нормализация

`scripts/analyze_contrasts.py` читает `outputs/research/multimodal/trial_features.csv`, извлекает те же признаки для ответов «Базы» и сохраняет результат в `outputs/research/contrasts/`.

```powershell
python scripts/analyze_contrasts.py
```

| Шаг | Правило |
|---|---|
| Метки | «Правда» — `label=0`, «Ложь» — `label=1`; «База» — ответы темы «Нейтральные вопросы» из `session_summary.session_stages`, кроме размеченных ответов |
| Признаки | Латентность и слоги/с ответа, 5 речевых, 4 видео, ЧСС и RMSSD ЭКГ в окне 120 с; норма вектора акустических аномалий |
| Диалог | Латентность — `latency_s` пары, отрицательная — NaN; слоги/с — гласные реплик респондента ответа / их суммарная длительность |
| Нормализация | `z = (x − медиана «Базы») / (IQR всех ответов участника / 1.349)`, ограничение `[−5; 5]`; нужно ≥ 2 значения «Базы» и ≥ 4 ответа с признаком |
| Аномалии | Корень из среднего квадрата доступных z пяти речевых признаков |
| Контраст | Среднее z «Лжи» − среднее z «Правды», один на участника и признак |
| H1 | Точный двусторонний тест перестановки знаков; минимум 6 участников |
| Ожидаемое направление | `contrasts.EXPECTED`: рост латентности, пауз, F0, ЧСС и нормы аномалий; снижение темпа, движений головы и торса, RMSSD. В результат записывается число участников с контрастом этого знака; тест H1 остаётся двусторонним |
| H2 | Ведущий естественный тип «Содействующий» против остальных; точный перестановочный тест разности средних; минимум 3 участника в группе |
| H3 | Спирмен контраста и выраженности; точные перестановки; минимум 6 участников |
| Поправка | Холм отдельно для H1, H2 и H3 по рассчитанным признакам |
| Модели | LOPO как выше: исходные признаки, нормированные, нормированные + профили; Δ Brier с bootstrap по участникам |

Выход: `answers.csv`, `normalized_answers.csv`, `participant_contrasts.csv`, `hypothesis_tests.csv`, `summary.json`.

## Результаты

В выходном каталоге сохраняются признаки участников и ответов, корреляции, прогнозы, проверка сдвигов, `analysis_plan.json`, `summary.json`, хеши источников, состав обучающих наборов, версии библиотек и архив воспроизведения.
