# Исходные данные

Проект ожидает папку, указанную в `NTI_DATA_ROOT` (по умолчанию родительская папка проекта):

```text
dataset/
  Participant01.bcrx
  Session1.bcsx
  Результаты.xlsx
  1_30/
    00001_Participant01.MTS
  nti-lab/
```

Имя участника после первого подчёркивания в видео должно совпадать с именем BCRX. Само совпадение имени связывает записи, но не устанавливает временное смещение.

Письменные истории и подтверждение их истинности хранятся локально в `data/private/stories.json`; исходные документы, ссылки, хеши, сопоставления профилей и ручные метки также остаются в `private/`. В поставленном локальном наборе они уже подготовлены из материалов владельца.

Для другого исследования заполните такую же схему на данных, которые разрешено обрабатывать. Не загружайте исходные записи людей в публичный репозиторий. Пример единичной истории:

```json
{
  "stories": [{
    "story_id": "Participant01_story_01",
    "participant_id": "Participant01",
    "title": "Тема",
    "text": "Подтверждённый исходный рассказ",
    "source_url": null,
    "declared_truth_label": "truth",
    "label_provenance": "явное подтверждение автора набора"
  }]
}
```
